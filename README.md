# Voice Assistant using Python

A simple Python-based voice assistant that listens to user voice commands and performs actions such as Google search and opening websites.

## Features
- Voice input via microphone
- Speech-to-text using Google Speech Recognition
- Google search via voice
- Open YouTube via command
- Clean and extensible architecture

## Technologies Used
- Python
- SpeechRecognition
- PyAudio

## How to Run

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python main.py
